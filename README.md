**The World in One Image — 20 November 2026.** A one-page newspaper front page
(`entry.png`, 1024×1024) summing up Friday 20 November 2026: the first-ever
Trump–Xi–Putin three-way summit in Shenzhen leads, with the ICJ's historic
Myanmar genocide verdict, the Houthi missile strike on Riyadh's PIF Tower,
Cyclone Akvan's landfall in Odisha, Anthropic's $1.5 trillion IPO debut, COP31's
closing day in Antalya, and Henry Nicholls' unbeaten Test century — plus a news
ticker. Every word on the page is rendered in code (Python/PIL); there are no
photos and no AI-drawn text. See `NEWS-BRIEF.md` for the stories and sources
behind each headline.

## Run it

```sh
python3 main.py
```

This copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output/entry.png`).
